# Smart-Low-light-image-enhacement-using-U-Net
This project focuses on enhancing the visibility and quality of images captured in poorly lit environments using deep learning and image processing techniques. A U-Net-based model was implemented to intelligently enhance brightness, contrast, and color balance while preserving natural details. In addition, techniques such as CLAHE, gamma correction, and white balance were applied to refine image clarity and reduce noise. The system is built with Python and an interactive Streamlit-based web interface, allowing users to upload or capture real-time images, adjust enhancement parameters, and instantly visualize results. The project supports multiple image formats (JPG, PNG, RAW, DNG) and can be used in surveillance, medical imaging, photography, and autonomous systems.
